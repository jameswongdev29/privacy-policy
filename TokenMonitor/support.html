Token Monitor Support

Local usage monitoring and account management for Codex and Claude Code on macOS 14 or later.

Getting started

Open the menu bar waveform icon. In Settings, choose Codex or Claude and authorize its data directory using the system picker. Hidden directories are visible: select .codex or .claude in your home directory, or your custom configuration directory. Statistics combine both sources. Only locally recorded usage is available.

Explore without connecting an account

Choose Explore sample data on the initial Usage page, in Settings, or on the expired-trial page. All four tabs have populated sample content. Try account switching and Undo using the sample accounts, or import the built-in third sample account. Claude directory management and CSV export also work with sample data. Exit demo returns to your own data and purchase state. This is always labeled sample data and does not restart your trial or unlock real-data use.

Account switching

For Codex file-based login, save the current account or import auth.json. Confirm Switch, then reopen the Codex client. The previous login is backed up in Keychain. Undo is available unless Codex has since changed its login file. Keyring, auto and ephemeral login storage are not supported. Avoid signing in or refreshing credentials during a switch.

Claude profiles

Add directories already used by Claude Code. Copy the launch command and run it yourself in Terminal to use a profile. Token Monitor never launches Claude or copies its login credentials.

Costs and missing usage

Amounts are estimates at bundled standard API prices, not subscription bills. Unknown models remain unpriced. Log changes, missing records and revoked directory access can affect totals. Reauthorize a moved directory in Settings.

Trial and lifetime license

A seven-day full-app trial starts automatically at first use. All features are available during the trial. After it ends, the panel shows purchase and restore instructions, with a separate sample-data demo entrance. Purchase once for lifetime use (US $0.99; local price shown by Apple), with no subscription or automatic charge. Connected directories and local data are retained. Restore purchases uses the same Apple account and does not restart an existing trial.

Contact

Email support.jamesstudio@gmail.com with the app version, macOS version and a description of the problem. Never attach auth.json, API keys, access tokens or private conversation logs.
