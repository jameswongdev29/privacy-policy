Token Monitor Privacy Policy

Effective October 10, 2026. Developer: Weidi Huang. Applies to Token Monitor for macOS.

Local data processing

Token Monitor reads Codex and Claude Code usage logs in directories you select. Log files may contain conversation text, tool output and account identifiers; the app parses these files locally to extract token counts, model names, event times, session identifiers and quota snapshots. It does not upload logs, conversations or credentials to the developer or a third-party AI service. We operate no app server and include no advertising, analytics or third-party SDK.

Accounts and directory access

Codex account management reads login information, which may contain an email address, account identifiers, API keys and access or refresh tokens. Accounts you save or import and the backup for the latest switch are stored in the macOS Keychain. Account labels and identifiers, directory paths and switch recovery metadata are stored locally. Switching or undoing a switch changes auth.json in the Codex directory you selected, after your confirmation. The app does not sign you into a website or modify browser cookies. Claude credentials are not read or copied.

The Mac App Store build uses the macOS App Sandbox. System file pickers grant access to selected directories and files. Directory bookmarks are stored locally so access can resume after restarting. You may revoke directory access in Settings. Usage logs are read-only; Codex directory write access is used for confirmed account switching.

Retention and deletion

Preferences and directory records remain locally until you remove them or reset the app. Removing a saved account deletes its saved Keychain entry, but does not sign out Codex or delete the latest switch backup. Usage statistics are also saved in the app container so they remain viewable and exportable after the trial ends. This snapshot excludes account identifiers, quotas, credentials and conversation content; session identifiers are hashed. Revoking a source directory clears its source's saved statistics. Exported CSV files remain wherever you save them and can be deleted using Finder. Removing the app may leave its container data and Keychain entries. To remove all data, delete the app's local container data and its Keychain entries under com.cgwang.AIMonitor.credentials, including switch backups. This does not remove Codex or Claude Code's own logs and login files.

Purchases and support

In the Mac App Store release, trial and lifetime purchases are processed by Apple through StoreKit. The app verifies purchase information locally to determine trial and unlock status; the developer does not receive payment card details. Apple handles App Store transactions under Apple's Privacy Policy. Support messages are sent only when you choose to send them using your mail app. Do not send login files, tokens or private conversations.

Contact and changes

Contact support.jamesstudio@gmail.com. See the support page. Policy updates will be published with a revised date.

Token Monitor 隐私政策

生效日期：2026 年 10 月 10 日。开发者：Weidi Huang。

本地处理

应用读取你选择的 Codex 与 Claude Code 用量日志。原始日志可能含对话、工具输出和账号标识；应用仅在本机解析 Token 计数、模型、时间、会话标识和额度快照，不向开发者或第三方 AI 服务上传日志、对话或凭据。应用没有自建服务器、广告、分析或第三方 SDK。

账号与目录权限

Codex 账号管理会读取可能含邮箱、账号标识、API Key、访问和刷新 Token 的登录文件。保存或导入的凭据及最近切换的备份存入 macOS 钥匙串；账号名称、标识、目录路径和恢复元信息保存在本机。切换和撤销操作经你确认后修改所选 Codex 目录的 auth.json，不改写浏览器 Cookie。应用不读取或复制 Claude 登录凭据。

Mac App Store 版本启用沙盒，通过系统文件窗口获得所选目录和文件权限，并在本机保存目录授权书签以供重启后使用。设置中可撤销目录授权。日志只读；Codex 目录写权限用于确认后的账号切换。

保留与删除

偏好和目录记录在移除或重置前保留在本机。移除已保存账号会删除其钥匙串条目，但不会登出 Codex 或删除最近切换的恢复备份。用量统计也保存在应用容器中，便于试用结束后继续查看和导出；该快照不含账号标识、额度、凭据或对话内容，会话标识以哈希保存。撤销来源目录授权会清除该来源的已保存统计；CSV 保留在你选择的位置，可在 Finder 删除。卸载应用可能保留容器数据和钥匙串条目；完全清除时需删除本应用的本地容器数据，并在钥匙串中清除 com.cgwang.AIMonitor.credentials 下的条目，包括切换备份。不会删除 Codex 或 Claude 自身的日志和登录文件。

购买与支持

Mac App Store 发布版中，试用和永久购买由 Apple StoreKit 处理，应用在本机验证交易以判断使用权限，开发者不会获得银行卡信息。Apple 按其隐私政策处理交易。支持邮件仅在你自行发送时送出；请勿发送登录文件、Token 或私人对话。
